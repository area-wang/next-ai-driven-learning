# LLM 联网搜索集成功能需求文档

## 1. 功能概述

为 AI 学习平台的 LLM 调用增加**可选的**联网搜索能力。用户可以在每次调用 LLM 时决定是否启用联网搜索，让 AI 在生成内容前自动搜索最新的互联网信息，提高回答的准确性和时效性。

**核心设计理念**：
1. **场景级开关**：开关放在具体调用 LLM 的界面上（对话界面、生成大纲界面等），用户每次使用时可以自主选择
2. **集中参数配置**：搜索参数（结果数量、语言等）统一在设置页配置，避免每次使用时重复设置

## 2. 背景与目标

### 2.1 背景
当前系统使用多个 AI 提供商（OpenAI、DeepSeek、Gemini、Claude、Cloudflare AI）生成学习内容，但这些模型的知识截止日期有限，无法获取最新信息。

### 2.2 目标
- **主要目标**：提供一个简单的联网搜索开关，用户可以自主控制
- 在生成内容前自动搜索相关信息（当开关启用时）
- 将搜索结果作为上下文提供给 LLM
- 提高生成内容的准确性和时效性
- 保持简单易用，不增加用户使用负担

## 3. 用户故事

### 3.1 作为学习者
**故事**: 我想要获取最新的技术知识和信息  
**场景**: 当我询问关于最新技术（如 React 19、Next.js 15）的问题时  
**期望**: AI 能够搜索最新的文档和资料，提供准确的最新信息

### 3.2 作为内容创建者
**故事**: 我想要生成包含最新信息的学习大纲  
**场景**: 当我创建学习计划或大纲时  
**期望**: 系统能够自动搜索相关的最新资料，生成更准确的学习路径

### 3.3 作为普通用户
**故事**: 我想要简单地控制是否使用联网搜索  
**场景**: 有时我需要最新信息，有时不需要  
**期望**: 有一个清晰的开关，让我可以随时启用或禁用联网搜索功能

## 4. 功能需求

### 4.1 搜索服务集成

#### 4.1.1 搜索 API 选择
- **必需**: 集成至少一个搜索 API（推荐：Tavily、Serper、Brave Search）
- **必需**: 支持配置搜索 API 密钥
- **可选**: 支持多个搜索提供商，可切换

#### 4.1.2 搜索参数配置（设置页）
在 AI 设置页面（`/settings/ai`）添加搜索参数配置区域：

- **必需**: 搜索结果数量（下拉选择：3/5/10 条，默认 5 条）
- **必需**: 搜索语言（下拉选择：中文/英文/自动，默认自动）
- **可选**: 搜索时间范围（下拉选择：不限/最近一周/最近一月/最近一年，默认不限）
- **可选**: 搜索域名白名单（文本输入，多个域名用逗号分隔）
- **必需**: 参数配置保存到用户配置（数据库）
- **必需**: 显示参数说明和推荐值

### 4.2 搜索触发机制（开关设计）

#### 4.2.1 场景级开关（优先实现）
开关直接放在具体调用 LLM 的界面上，用户可以在每次使用时决定是否启用联网搜索：

- **必需**: 在 AI 对话界面添加"联网搜索"开关/复选框
- **必需**: 在学习计划生成界面添加"使用联网搜索"复选框
- **必需**: 在学习大纲生成界面添加"使用联网搜索"复选框
- **必需**: 在学习内容生成界面添加"使用联网搜索"复选框
- **必需**: 在测试题生成界面添加"使用联网搜索"复选框
- **必需**: 开关默认关闭（避免意外成本）
- **必需**: 开关旁边显示简短说明（如"搜索最新信息"）

#### 4.2.2 开关状态记忆（可选）
- **可选**: 记住用户上次的选择（使用 localStorage）
- **可选**: 下次打开时自动恢复上次的开关状态

### 4.3 搜索结果处理

#### 4.3.1 结果提取
- **必需**: 提取搜索结果的标题、URL、摘要
- **必需**: 过滤无关或低质量结果
- **可选**: 提取网页完整内容（针对重要结果）

#### 4.3.2 结果整合
- **必需**: 将搜索结果格式化为结构化文本
- **必需**: 在 LLM prompt 中添加搜索结果作为上下文
- **必需**: 明确标注信息来源（URL）

### 4.4 UI/UX 改进

#### 4.4.1 开关界面设计
- **必需**: 在每个调用 LLM 的界面添加清晰的开关/复选框
- **必需**: 开关旁边显示简短说明（如"🌐 联网搜索"）
- **必需**: 开关位置明显但不突兀（建议放在提交按钮附近）
- **必需**: 开关有 hover 提示（显示详细说明）

#### 4.4.2 搜索状态显示
- **必需**: 当开关启用时，显示"正在搜索最新信息..."加载状态
- **必需**: 显示搜索完成提示（如"✓ 已搜索 3 条相关信息"）
- **可选**: 显示搜索使用的关键词

#### 4.4.3 结果展示
- **必需**: 在生成的内容中标注引用来源
- **可选**: 显示搜索到的参考链接列表
- **可选**: 允许用户查看原始搜索结果

### 4.5 适用场景（全部必需支持）

所有以下场景都必须支持联网搜索功能，当用户启用全局开关时，这些场景都会自动使用联网搜索：

#### 4.5.1 AI 对话助手
- **API**: `/api/ai/chat`
- **场景**: 用户与 AI 进行对话交流
- **搜索价值**: 回答最新技术问题、时事相关问题
- **实现优先级**: P0（最高）

#### 4.5.2 学习计划生成
- **API**: `/api/learning-plan/generate`
- **场景**: 根据主题生成完整的学习计划
- **搜索价值**: 获取最新的学习路径、技术趋势、推荐资源
- **实现优先级**: P0（最高）

#### 4.5.3 学习大纲生成
- **API**: `/api/learning-outline/generate`
- **场景**: 为学习计划生成详细的知识大纲
- **搜索价值**: 确保大纲内容符合最新标准和最佳实践
- **实现优先级**: P0（最高）

#### 4.5.4 学习内容生成
- **API**: `/api/learning-content/generate`
- **场景**: 为大纲节点生成详细的学习内容
- **搜索价值**: 提供最新的技术文档、示例代码、最佳实践
- **实现优先级**: P0（最高）

#### 4.5.5 学习测试题生成
- **API**: `/api/test-questions/generate`
- **场景**: 根据学习内容生成测试题
- **搜索价值**: 参考最新的考试题型、技术面试题
- **实现优先级**: P0（最高）

## 5. 非功能需求

### 5.1 性能要求
- 搜索请求响应时间 < 3 秒
- 不应显著增加 LLM 调用的总时间（目标：增加 < 5 秒）
- 支持并发搜索请求

### 5.2 可靠性要求
- 搜索失败时应降级到普通 LLM 调用
- 提供清晰的错误提示
- 记录搜索失败日志

### 5.3 安全性要求
- 搜索 API 密钥安全存储（环境变量）
- 过滤恶意或不安全的搜索结果
- 防止搜索注入攻击

### 5.4 成本控制
- 记录搜索 API 调用次数
- 支持设置每日/每月搜索配额
- 提供搜索使用统计

## 7. 技术约束

### 7.1 技术栈
- Next.js 16.0.7
- TypeScript 5.9.3
- Cloudflare Workers（部署环境）
- Drizzle ORM（数据库）

### 7.2 兼容性
- 必须兼容现有的 AI 客户端架构（`src/lib/ai/client.ts`）
- 必须支持所有现有的 AI 提供商
- 不应破坏现有的 API 接口

### 7.3 推荐的搜索 API
1. **Tavily API** - 专为 AI 应用设计，返回结构化结果
2. **Serper API** - Google 搜索 API，结果质量高
3. **Brave Search API** - 隐私友好，免费额度较高

## 8. 实现优先级

### P0（必须实现 - MVP）

#### 阶段 1：基础设施（第 1-2 天）
1. **数据库 Schema 更新**
   - 在用户配置表中添加搜索参数字段：
     - `searchResultCount`（整数，默认 5）
     - `searchLanguage`（字符串，默认 'auto'）
   - 运行数据库迁移

2. **搜索 API 集成**
   - 集成 Tavily Search API
   - 创建搜索服务模块（`src/lib/search/tavily.ts`）
   - 创建搜索工具函数（`src/lib/search/utils.ts`）
   - 环境变量配置（`TAVILY_API_KEY`）

3. **搜索参数配置 UI（设置页）**
   - 在 AI 设置页面（`/settings/ai`）添加搜索参数配置区域
   - 参数配置读取和保存 API（`/api/ai/search-config`）
   - 参数说明文字和推荐值

#### 阶段 2：核心场景集成（第 3-5 天）
4. **5 个核心场景的 UI 开关和 API 集成**（按顺序实现）
   
   a. **AI 对话助手**
   - 前端：在对话界面添加"联网搜索"开关
   - API（`/api/ai/chat`）：接收 `enableWebSearch` 参数
   - 当开关启用时，先搜索再调用 LLM
   - 将搜索结果添加到 prompt 上下文
   
   b. **学习计划生成**
   - 前端：在生成界面添加"使用联网搜索"复选框
   - API（`/api/learning-plan/generate`）：接收 `enableWebSearch` 参数
   - 根据学习主题搜索相关资源
   - 将搜索结果整合到学习计划生成 prompt
   
   c. **学习大纲生成**
   - 前端：在生成界面添加"使用联网搜索"复选框
   - API（`/api/learning-outline/generate`）：接收 `enableWebSearch` 参数
   - 搜索主题相关的最新知识点
   - 优化大纲结构和内容
   
   d. **学习内容生成**
   - 前端：在生成界面添加"使用联网搜索"复选框
   - API（`/api/learning-content/generate`）：接收 `enableWebSearch` 参数
   - 搜索具体知识点的详细资料
   - 提供最新的示例和最佳实践
   
   e. **学习测试题生成**
   - 前端：在生成界面添加"使用联网搜索"复选框
   - API（`/api/test-questions/generate`）：接收 `enableWebSearch` 参数
   - 搜索相关的考试题型和面试题
   - 确保测试题的时效性和准确性

5. **基本错误处理**
   - 搜索失败时降级到普通 LLM 调用
   - 显示友好的错误提示
   - 日志记录搜索失败原因

#### 阶段 3：用户体验优化（第 6 天）
6. **搜索状态显示**
   - 显示"正在搜索最新信息..."加载状态
   - 显示搜索完成提示（如"✓ 已搜索 3 条相关信息"）

7. **信息来源标注**
   - 在生成内容中标注参考来源 URL
   - 格式化显示搜索来源

### P1（高优先级 - 第 7-8 天）
- 搜索使用日志记录（记录搜索次数、关键词、结果数）
- 搜索使用统计显示（在设置页面显示本月使用次数）
- 开关状态记忆（使用 localStorage 记住用户上次的选择）
- 更多搜索参数配置（时间范围、域名白名单等）

### P2（中优先级 - 后续迭代）
- 搜索结果缓存（避免重复搜索相同内容）
- 搜索关键词智能提取和优化
- 显示原始搜索结果列表（可展开查看）
- 用户反馈机制（标记有用/无用的搜索结果）

### P3（低优先级 - 未来规划）
- 多搜索提供商支持（Serper、Brave Search）
- 网页内容完整提取（针对重要结果）
- 高级过滤和排序
- 搜索结果的向量化存储
- 基于搜索历史的智能推荐

## 9. 风险与挑战

### 9.1 技术风险
- 搜索 API 可能不稳定或限流
- 搜索结果质量可能不稳定
- 增加的延迟可能影响用户体验

### 9.2 成本风险
- 搜索 API 调用可能产生额外成本
- 需要合理控制使用频率

### 9.3 质量风险
- 搜索结果可能包含错误或过时信息
- LLM 可能误解或误用搜索结果

## 10. 后续迭代方向

- 支持更多搜索源（学术论文、技术文档）
- 智能搜索关键词提取
- 搜索结果缓存和复用
- 用户反馈机制（标记有用/无用的搜索结果）
- 搜索结果的向量化存储和检索

# 学习方法集成系统 - 需求文档

## 1. 项目概述

### 1.1 背景
当前平台提供了 AI 驱动的学习内容生成和测试功能，但缺少科学的学习方法指导。为了帮助用户更有效地学习和巩固知识，需要集成多种经过验证的学习方法。

### 1.2 目标
- 集成 6 种主流学习方法到现有平台
- 为每种学习方法提供专门的工具和界面
- 通过 AI 辅助用户应用这些学习方法
- 追踪学习进度和复习计划
- 提供数据可视化和学习分析

## 2. 核心学习方法

### 2.1 费曼学习法 (Feynman Technique)
**原理**: 通过用简单的语言向他人解释概念来检验和深化理解

**核心步骤**:
1. 选择一个概念
2. 用自己的话解释给"小白"听
3. 识别知识盲点
4. 简化和类比

**平台集成方式**:
- 提供"费曼解释"编辑器
- AI 扮演"学生"角色，提出问题
- 自动识别解释中的模糊点
- 生成简化建议和类比

### 2.2 艾宾浩斯遗忘曲线 (Ebbinghaus Forgetting Curve)
**原理**: 根据遗忘规律安排复习时间，在即将遗忘时复习效果最好

**复习时间点**:
- 第 1 次：学习后 20 分钟
- 第 2 次：学习后 1 天
- 第 3 次：学习后 2 天
- 第 4 次：学习后 4 天
- 第 5 次：学习后 7 天
- 第 6 次：学习后 15 天
- 第 7 次：学习后 30 天

**平台集成方式**:
- 自动生成复习计划
- 智能提醒系统
- 复习内容自动推送
- 复习效果追踪

### 2.3 卢曼卡片盒笔记法 (Zettelkasten)
**原理**: 通过原子化笔记和双向链接构建知识网络

**核心原则**:
- 一卡片一概念
- 用自己的话记录
- 建立笔记间的链接
- 定期回顾和重组

**平台集成方式**:
- 卡片式笔记编辑器
- 双向链接功能
- 知识图谱可视化
- 标签和分类系统

### 2.4 康奈尔笔记法 (Cornell Note-Taking)
**原理**: 结构化笔记，分为笔记区、线索区和总结区

**笔记结构**:
- 笔记区 (右侧 70%): 记录主要内容
- 线索区 (左侧 30%): 关键词、问题
- 总结区 (底部): 用 2-3 句话总结

**平台集成方式**:
- 康奈尔笔记模板
- 自动提取关键词
- AI 生成总结
- 转换为测试题

### 2.5 番茄工作法 (Pomodoro Technique)
**原理**: 25 分钟专注学习 + 5 分钟休息，提高专注力

**工作流程**:
- 25 分钟专注学习
- 5 分钟短休息
- 4 个番茄钟后，15-30 分钟长休息

**平台集成方式**:
- 番茄钟计时器
- 学习统计和分析
- 专注模式（屏蔽干扰）
- 学习记录和回顾

### 2.6 间隔重复 (Spaced Repetition)
**原理**: 根据记忆强度动态调整复习间隔

**算法**: SuperMemo SM-2 算法
- 根据回忆难度调整间隔
- 简单的内容间隔更长
- 困难的内容间隔更短

**平台集成方式**:
- 闪卡系统
- 智能复习算法
- 记忆强度追踪
- 学习统计

## 3. 用户故事

### 3.1 费曼学习法
**作为** 学习者  
**我想要** 用简单的语言解释我学到的概念  
**以便** 检验我是否真正理解了这个知识点

**验收标准**:
- [ ] 可以创建费曼解释文档
- [ ] AI 可以扮演学生角色提问
- [ ] 系统可以识别解释中的模糊点
- [ ] 可以保存和回顾解释历史

### 3.2 艾宾浩斯复习计划
**作为** 学习者  
**我想要** 系统自动为我安排复习时间  
**以便** 在最佳时机复习，提高记忆效果

**验收标准**:
- [ ] 学习内容自动生成复习计划
- [ ] 到期时收到复习提醒
- [ ] 可以查看复习日历
- [ ] 可以追踪复习完成情况

### 3.3 卡片盒笔记
**作为** 学习者  
**我想要** 创建原子化的知识卡片并建立链接  
**以便** 构建我的个人知识网络

**验收标准**:
- [ ] 可以创建卡片式笔记
- [ ] 可以在笔记间建立双向链接
- [ ] 可以查看知识图谱
- [ ] 可以通过标签组织笔记

### 3.4 康奈尔笔记
**作为** 学习者  
**我想要** 使用康奈尔笔记法记录学习内容  
**以便** 更好地组织和复习知识

**验收标准**:
- [ ] 可以使用康奈尔笔记模板
- [ ] 系统自动提取关键词到线索区
- [ ] AI 可以生成总结
- [ ] 可以将笔记转换为测试题

### 3.5 番茄工作法
**作为** 学习者  
**我想要** 使用番茄钟来管理学习时间  
**以便** 保持专注并避免疲劳

**验收标准**:
- [ ] 可以启动番茄钟计时器
- [ ] 到时自动提醒休息
- [ ] 可以查看学习统计
- [ ] 可以设置专注模式

### 3.6 间隔重复
**作为** 学习者  
**我想要** 使用闪卡进行间隔重复练习  
**以便** 长期记住重要知识点

**验收标准**:
- [ ] 可以创建闪卡
- [ ] 系统根据记忆强度安排复习
- [ ] 可以标记回忆难度
- [ ] 可以查看记忆曲线

## 4. 功能需求

### 4.1 学习方法选择器
- 在学习计划创建时选择学习方法
- 支持多种方法组合使用
- 提供方法介绍和使用指南

### 4.2 费曼学习工具
- 费曼解释编辑器
- AI 学生对话系统
- 知识盲点识别
- 简化建议生成

### 4.3 复习计划系统
- 艾宾浩斯复习计划生成
- 复习提醒和推送
- 复习日历视图
- 复习效果追踪

### 4.4 卡片盒笔记系统
- 卡片创建和编辑
- 双向链接功能
- 知识图谱可视化
- 标签和搜索

### 4.5 康奈尔笔记工具
- 三栏笔记模板
- 关键词自动提取
- AI 总结生成
- 笔记转测试题

### 4.6 番茄钟工具
- 计时器功能
- 学习统计
- 专注模式
- 学习记录

### 4.7 闪卡系统
- 闪卡创建和管理
- SM-2 算法实现
- 复习队列
- 统计分析

## 5. 非功能需求

### 5.1 性能
- 复习提醒延迟 < 1 分钟
- 知识图谱渲染 < 2 秒
- 闪卡翻转动画流畅 (60fps)

### 5.2 可用性
- 学习方法切换无缝
- 移动端友好
- 离线支持（番茄钟、闪卡）

### 5.3 数据
- 学习数据本地存储
- 支持数据导出
- 隐私保护

## 6. 技术约束

### 6.1 前端
- React + TypeScript
- 使用现有的 Tiptap 编辑器
- 图表库：Recharts 或 D3.js
- 知识图谱：React Flow 或 Cytoscape.js

### 6.2 后端
- Next.js API Routes
- Drizzle ORM
- Cloudflare D1 数据库

### 6.3 AI 集成
- 使用现有的 OpenRouter API
- 支持多模型选择

## 7. 实施优先级

### P0 (核心功能)
1. 艾宾浩斯复习计划系统
2. 闪卡系统（间隔重复）
3. 番茄钟工具

### P1 (重要功能)
4. 费曼学习工具
5. 康奈尔笔记模板

### P2 (增强功能)
6. 卡片盒笔记系统（知识图谱）

## 8. 成功指标

- 用户使用学习方法的比例 > 60%
- 复习计划完成率 > 70%
- 用户平均学习时长提升 30%
- 测试成绩提升 20%
- 用户满意度 > 4.5/5

## 9. 风险和挑战

### 9.1 技术风险
- 知识图谱性能优化
- 复习提醒的可靠性
- 离线功能实现

### 9.2 用户体验风险
- 学习方法学习曲线
- 功能过多导致混乱
- 移动端体验

### 9.3 缓解措施
- 渐进式功能引导
- 提供使用教程
- 简化初始配置
- 响应式设计优化

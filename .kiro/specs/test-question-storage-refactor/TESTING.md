# 测试题存储重构 - 测试指南

## 测试目标

验证测试题从HTML解析改为数据库存储的重构是否成功。

## 测试环境准备

1. **确保数据库迁移已应用**
   ```bash
   npm run db:migrate:local
   ```

2. **启动开发服务器**
   ```bash
   npm run dev
   ```

## 测试场景

### 场景1：生成新测试题（验证保存到数据库）

**步骤：**
1. 打开任意学习计划详情页面
2. 选择一个普通文档（非测试题文档）
3. 点击"生成测试题"按钮
4. 配置测试题参数：
   - 题目数量：5
   - 难度：中等
   - 题型：选择题、填空题
5. 点击"生成"按钮
6. 等待生成完成

**预期结果：**
- ✅ 生成成功提示
- ✅ 创建新的测试题文档
- ✅ 题目正确显示在编辑器中
- ✅ 题目保存到数据库（后续场景验证）

**验证数据库：**
```bash
# 查看数据库中的题目
sqlite3 .wrangler/state/v3/d1/miniflare-D1DatabaseObject/*/db.sqlite "SELECT * FROM test_questions ORDER BY created_at DESC LIMIT 5;"
```

---

### 场景2：答题（验证从API读取）

**步骤：**
1. 在场景1生成的测试题文档中
2. 点击"开始答题"按钮
3. 观察题目是否正确显示

**预期结果：**
- ✅ 所有题目都正确显示
- ✅ 题目数量与生成时一致
- ✅ 题目内容、选项、题型都正确
- ✅ 答题卡显示正确的题目数量

**验证API调用：**
打开浏览器开发者工具 → Network 标签，查看以下请求：
1. `GET /api/learning-outline/[outlineId]/content` - 应该返回 `contentId`
2. `GET /api/test-questions/[contentId]` - 应该返回题目列表

---

### 场景3：覆盖模式（验证更新数据库）

**步骤：**
1. 在已有的测试题文档中
2. 点击"生成测试题"按钮
3. 修改参数：
   - 题目数量：10
   - 难度：困难
   - 题型：简答题、编程题
4. 点击"生成"按钮
5. 等待生成完成

**预期结果：**
- ✅ 原有题目被覆盖
- ✅ 新题目正确显示
- ✅ 题目数量变为10
- ✅ 题型变为简答题和编程题

**验证数据库：**
```bash
# 查看该内容的题目数量
sqlite3 .wrangler/state/v3/d1/miniflare-D1DatabaseObject/*/db.sqlite "SELECT COUNT(*) FROM test_questions WHERE content_id = '[contentId]';"
```

---

**预期结果：**

## 常见问题

### Q1: 数据库迁移失败
**解决方案：**
```bash
# 删除本地数据库
rm -rf .wrangler/state

# 重新运行迁移
npm run db:migrate:local
```

### Q2: API返回404
**原因：** 可能是旧的测试题文档，数据库中没有对应的题目记录
**解决方案：** 这是正常的，系统会自动降级到HTML解析

### Q3: 题目显示不全
**检查：**
1. 查看浏览器控制台是否有错误
2. 查看Network标签，API是否返回数据
3. 查看数据库中是否有题目记录

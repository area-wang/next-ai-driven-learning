# 富文本编辑器使用指南

## 功能概述

本平台集成了功能强大的富文本编辑器，支持多种内容类型和交互方式。

## 基础功能

### 文本格式
- **粗体**：Ctrl/Cmd + B 或选中文本后点击工具栏 B 按钮
- **斜体**：Ctrl/Cmd + I 或选中文本后点击工具栏 I 按钮
- **删除线**：Ctrl/Cmd + Shift + X 或选中文本后点击工具栏 S 按钮
- **行内代码**：选中文本后点击工具栏 `<>` 按钮

### 标题
输入 `/` 然后选择标题级别（H1-H6），或使用浮动工具栏：
- H1：最大标题
- H2：主要章节
- H3：子章节
- H4-H6：更细的层级

### 列表
- **无序列表**：输入 `/无序` 或 `- ` 开头
- **有序列表**：输入 `/有序` 或 `1. ` 开头
- **任务列表**：输入 `/任务` 或 `- [ ] ` 开头

### 引用和代码
- **引用块**：输入 `/引用`
- **代码块**：输入 `/代码`，支持语法高亮

### 链接
1. 选中文本
2. 点击浮动工具栏的链接图标
3. 输入 URL

## 高级功能

### 颜色
选中文本后点击调色板图标：
- **字体颜色**：8种预设颜色（黑、灰、红、橙、黄、绿、蓝、紫）
- **背景颜色**：8种浅色背景

### 对齐
选中文本后选择对齐方式：
- 左对齐
- 居中
- 右对齐
- 两端对齐

### 媒体内容

#### 图片
三种方式插入图片：
1. 输入 `/图片` → 输入 URL
2. 拖拽图片文件到编辑器
3. 复制图片后粘贴（Ctrl/Cmd + V）

#### 视频
输入 `/视频` → 输入 YouTube 或 Vimeo URL

### 表格
1. 输入 `/表格` 创建 3x3 表格
2. 右键表格打开菜单：
   - 添加行（上方/下方）
   - 添加列（左侧/右侧）
   - 删除行/列
   - 删除整个表格
3. 拖动列边框调整宽度

### 数学公式
输入 `/数学` 插入 LaTeX 公式：
- **行内公式**：`$E = mc^2$`
- **块级公式**：
  ```
  $$
  \int_{a}^{b} f(x) dx = F(b) - F(a)
  $$
  ```

### 提示框
输入 `/` 然后选择提示框类型：
- **信息提示**：蓝色，用于显示重要信息
- **警告提示**：黄色，用于提醒注意事项
- **成功提示**：绿色，用于显示成功消息
- **错误提示**：红色，用于显示错误信息

## 使用技巧

### 1. 快速格式化
选中文本后使用键盘快捷键，比点击工具栏更快。

### 2. 列表嵌套
在列表项中按 Tab 创建子列表：
```
- 父项目
  - 子项目 1
  - 子项目 2
    - 孙项目
```

### 3. 表格编辑
在表格中右键打开菜单，快速添加/删除行列。

### 4. 颜色使用
适度使用颜色突出重点：
- 红色：错误、警告
- 绿色：成功、正确
- 蓝色：信息、链接
- 黄色：高亮、注意

### 5. 代码块语法高亮
指定编程语言以获得语法高亮：
````
```python
def hello():
    print("Hello, World!")
```
````

## 故障排除

### 问题 1：颜色继承
**症状**：应用颜色后，后续输入也是该颜色

**解决**：这个问题已修复。如果仍然出现，请刷新页面。

### 问题 2：工具栏不显示
**症状**：选中文本后工具栏不出现

**解决**：确保选中了文本（不是空选区）。

### 问题 3：图片上传失败
**症状**：拖拽图片后显示错误

**解决**：
1. 检查图片大小（建议 < 5MB）
2. 检查图片格式（支持 JPG、PNG、GIF）
3. 检查网络连接

### 问题 4：代码块没有语法高亮
**症状**：代码块显示为纯文本

**解决**：
1. 确认代码块指定了语言（例如：```python）
2. 清除浏览器缓存
3. 重新生成内容
